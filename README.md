# README Roast + Fixer

Roast and fix your README with clarity scores, missing-section checks, and rewrite suggestions.

## Features

- Paste any Markdown README and get an instant clarity score
- Choose between gentle, spicy, and savage roast modes
- Detect missing sections like Installation, Usage, License, and Contributing
- Generate a better project intro suggestion
- Get a practical checklist for the next README edits
- Works entirely in the browser with no API key

## Demo

Run it locally and paste your README into the editor.

## Installation

```bash
npm install
```

## Usage

```bash
npm run dev
```

Then open the local URL printed by Vite.

## Build

```bash
npm run build
```

## Test

```bash
npm test -- --run
```

## Tech Stack

- React
- TypeScript
- Vite
- Vitest

## Why this exists

Most open-source projects are judged by their README first. README Roast + Fixer helps developers quickly spot unclear docs, missing setup details, weak intros, and other issues that stop people from trying a project.
